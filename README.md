# anywh-sh/homebrew-tap

Homebrew tap for [anywh](https://github.com/anywh-sh/anywh)'s relay.

```
brew tap anywh-sh/tap
brew install anywh-relay
brew services start anywh-relay
```

`Formula/anywh-relay.rb` is written and pushed automatically by
[`publish.yml`](https://github.com/anywh-sh/anywh/blob/main/.github/workflows/publish.yml)
on every anywh release — not edited by hand.
